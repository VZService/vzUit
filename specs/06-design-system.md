# 06 · 设计系统执行规范

本文件是 B 端界面生成与审查时的判据来源，把设计系统的硬规则落成可直接照做的条目。
生成页面先过「六步工作流」，交付前过「二十五项门禁」，两处都过才算完。
色值与变量定义在 `src/tokens.css`，组件实现在 `src/components/`，本文件不重复贴代码。

## 六步工作流

1. 需求解构：抽出实体、角色、核心对象、操作频次、生命周期状态。频次决定主操作，状态决定徽标。
2. 模板匹配：列表页、详情页、看板、设置页、表单页、导入流，六选一，先定形态再画细节。
3. 布局骨架：页面标题区、筛选区、数据区、批量操作条，四段顺序固定，标题不许塞进内容卡。
4. 选型判据：Modal / Drawer / Popconfirm / Page 四选一，走下面「浮层取舍」的决策树。
5. 原子约束：按钮六态、唯一主操作、徽标浅底深字、4px 栅格、0.5px 微线。
6. 闭环走查：二十五项门禁逐条过。

## 三层 token

| 层 | 前缀 | 谁用 | 说明 |
|---|---|---|---|
| 基础色盘 | `--vz-palette-*` | 只有语义层引用 | 业务与组件禁止直接用，改一层全站联动 |
| 语义 | `--vz-bg-*` `--vz-text-*` `--vz-border-*` `--vz-primary*` `--vz-<状态>-bg` | 业务与组件必用 | 页面底色、承载面、文字四档、状态色与浅底都在这层 |
| 组件 | `--vz-radius-*` `--vz-control-*` `--vz-shadow-*` | 组件内部 | 尺寸与圆角阶梯，站点只改可变点做皮肤 |

亮色主题由 `[data-theme="light"]` 切换，语义层整体换值，组件层不动。页面没锁主题时跟随系统偏好。

## 视觉硬约束

- 常规卡片纯平，`1px solid var(--vz-hairline)` 切分，阴影只留给离屏浮层。
- 圆角按语义取，输入框 4、卡片 12、浮层 16、胶囊 999；按钮走 `--vz-radius-button`，VZ 系列默认胶囊，禁手写 `14px` 这类魔术值。
- 间距只取 4 的倍数，内边距四边对称。
- 字阶四档：页面标题 20/28、区块标题 16/24、正文 14/20、辅助 12/16。字号与行高成对取用。
- 数值区一律 `font-variant-numeric: tabular-nums`。
- 标题 `text-wrap: balance`，防孤字成行。
- 全页单一强调色，只有危险与成功终态才用红绿。
- 金额带千分位与单位，单位写在数值后不写在标题里。

## 原生控件一律覆盖

浏览器默认外观不许露出来。`src/components/controls.css` 已经把以下控件全部换成自绘版本：
`select`、`checkbox`、`radio`、开关、`range`、`file`、`number` 的上下箭头、`search` 的清除按钮、
日期与时间的图标、`progress`、`dialog`、滚动条、自动填充的淡黄底、`::selection` 与占位符。

三条规矩：

1. 新控件先在 `controls.css` 里加类，再来页面用，不许在业务 CSS 里就地 `appearance: none`。
2. 裸元素也走兜底样式（`vzuit.css` 里的 `input / textarea / select`），没加类不至于退回系统样式。
3. 第三方库自带的控件（picker、富文本工具条）要单独写覆盖，覆盖规则上方注明来源。

## 控件选型表

| 场景 | 用 | 禁用 |
|---|---|---|
| 互斥状态且立即生效（开关某项功能） | `input.vz-toggle` 或 `.vz-switch` | Checkbox、下拉 |
| 二选一动作随表单提交 | `.vz-check` 里的 radio | Switch（会被误读成立即生效） |
| 3 到 5 个互斥选项 | radio 平铺 | 下拉（多一次点击） |
| 6 个以上互斥选项 | `.vz-select` | radio 平铺 |
| 超过 10 个选项 | 带搜索的下拉 | 普通下拉 |
| 布尔字段随整表提交 | `.vz-check` checkbox | Switch |
| 多项勾选，选项少于 6 | checkbox 组合平铺 | 多选下拉 |
| 连续量（音量、透明度） | `.vz-range` | 分段选项卡 |
| 一组互斥主题或模式 | `.vz-seg` | 图标 toggle |

判据是「这组取值是不是互斥的多选项」，不是「界面上看着像不像开关」。

## 按钮

五档变体：`primary` 实心品牌（一个操作区只一个）、`secondary` 浅底微边、`ghost` 行内动作、
`danger` 危险动作、`link` 仅跳转语义。当前页的原地操作不许用 link 假扮。

六态必须齐全，缺一不许交付：

| 状态 | 要求 |
|---|---|
| default | 可识别可点，光标 pointer |
| hover | 150ms 内有反馈 |
| active | 下沉 1px |
| disabled | 置灰、`not-allowed`，文字仍可读 |
| loading | 嵌转圈，锁死防重复提交与重复扣费 |
| focus-visible | 只给键盘，环用 `--vz-focus-ring` |

宽度不许写死，`min-width: 80px` 配左右 padding，出海语言长两三倍时不撑破。
圆角走 `--vz-radius-button`，VZ 系列是胶囊，通用 B 端项目改这一个变量换成 6px 方角，不覆写按钮类。

文档页与视觉回归要一次看全六态时，用 `data-vz-state="hover|active|focus|disabled"` 把中间态定住，
样式与真实交互态出自同一条规则，不会两套写法漂移。业务代码不加这个属性。

## 徽标与标签

徽标只表系统客观状态，六种语义固定：success 完成、warning 待办审批、danger 真实阻断、
info 中性、processing 进行中、secondary 停用归档。80% 场景用浅底深字，实心只留给未读红点与灾难提示。
未完成不许用 danger，普通未完成走 info 或 warning。

标签表主观分类（VIP、大区），可删可筛，与徽标不混用。

红点三档：强阻断带数字，弱提示 6 到 8px 无字圆点，营销与常规通知不许挂红点。超过 99 显示 99+，只向左膨胀。

## 表格

- 文本左对齐，数值与时间右对齐，勾选居中。
- 操作列定宽 120px，贴右加微线，动作只给 ghost 或 link，超过三个收进更多菜单。
- 横滚只在 `.vz-table-wrap` 里发生，页面 `clientWidth` 必须等于 `scrollWidth`。
- 表头吸顶，紧凑模式内边距降到 8 / 12。
- 空态不许留只有表头的死表，要给原因与出口。

## 浮层取舍

先问三件事：影响多大、频次多高、要不要保留上下文。

| 情形 | 用 | 不用 |
|---|---|---|
| 高危不可逆且影响大 | Modal | Popconfirm |
| 高频轻量原地单项确认 | Popconfirm | 全屏阻断 |
| 短小录入（5 字段内）或宽幅预览 | Modal | Drawer |
| 需要对照列表的详情、多字段轻编辑、复杂筛选 | Drawer | Modal |
| 10 字段以上表单、分步向导、要独立 URL | 独立 Page | Modal、Drawer |

尺寸：Modal 400 / 520 / 720 到 800；Drawer 400 / 600 / 800。高度自适应，超一屏内部滚动，标题与底栏固定。
落点从视口 15vh 起，禁垂直正中。

遮罩：录入与高危层不响应点遮罩关闭，只有纯查看层用 `data-mask-closable="true"` 放行。
高危按钮文案写动宾与后果（「彻底删除（3 项）」），禁「是 / 确定」。
危险主按钮不默认聚焦，确认后进入 loading 并禁用取消与关闭。
Esc 可安全取消，焦点锁在浮层内。

能撤销的操作直接执行加撤销条，不先弹框拦。

## 反馈四层

按打扰程度从轻到重选，能落到更轻一档就不上更重的：

1. Tooltip：悬停补充说明，关键信息不许只放这里。
2. Toast：两秒自散，只报结果。
3. Alert 横幅：要持续可见又不阻断。
4. Popconfirm / Modal：需要用户给出结果才继续。

## 五态

Ideal 有数据、Empty 说明原因并给出口、Loading 小于 1 秒不铺骨架屏、Error 说清哪里错并给重试、
403 说明脱敏或申请权限。整页异常四要素：情境配图、错误代码与定性、大白话描述、两个出口。

## 演示数据

文档页、演示页、截图、示例代码里的数据一律用中性占位：示例选手一、示例选手二、示例赛季、示例订单。
真实用户名、甲方与需求方名称、真实对局记录、金额、手机号、邮箱都不许出现在对外可见的页面上。
对外工件的溯源信息只进内部档案，页面上不挂来源人。

## 二十五项门禁

交付前逐条过，全部通过才算完。

| 序号 | 检查点 |
|---|---|
| 01 | 阴影没被 `overflow` 祖先裁掉，余量不小于偏移加模糊加扩散 |
| 02 | 同心圆角，外圆角等于内圆角加内边距 |
| 03 | 分隔用 0.5px 或半透明微线，没有粗黑 1px |
| 04 | 弹窗落点 15vh，图标与文字光学重心对齐 |
| 05 | 没有占位废话文案，说明靠布局不靠标语 |
| 06 | 一个操作区只有一个主按钮 |
| 07 | 审批类二选一不设主按钮，两边都是 secondary |
| 08 | 徽标浅底深字，语义与变体一一对应 |
| 09 | 单选、开关、下拉按选型表选，没有下拉塞三个选项 |
| 10 | 录入与高危浮层点遮罩不关闭 |
| 11 | 高危操作有阻力：动宾文案、后果说明、二次确认或撤销条 |
| 12 | 表格三向对齐，数值右对齐并等宽 |
| 13 | 横滚隔离在表格容器内，页面无横向滚动条 |
| 14 | 五态覆盖，空态有出口 |
| 15 | 不手搓已有组件（分页、浮层、树、上传） |
| 16 | 数值区 `tabular-nums` |
| 17 | 标题防孤字 |
| 18 | 按钮不写死宽度，短词膨胀不撑破 |
| 19 | 多语言行高不裁切，阿语走逻辑属性 |
| 20 | 查询分层，超过一万条给显式查询与重置 |
| 21 | 时间选择有跨度防呆，格式统一 `YYYY-MM-DD HH:mm:ss` |
| 22 | 页面默认平，单一强调色，标题上方无装饰性小标签 |
| 23 | 按钮六态齐全 |
| 24 | 间距走 4px 栅格，内边距对称 |
| 25 | 按频次折叠低频操作，没有冗余说明文案 |

## 审查脚本

```
python3 scripts/audit-design-rules.py <待扫描目录>
```

脚本只覆盖已实现的正则规则，通过不代表走查完成。基座另有一套变量与漂移检查：

```
node tools/check-tokens.mjs src
```

两套都跑，都零报错再提交。
